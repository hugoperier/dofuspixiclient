# Règles retenues pour les douze classes

Le catalogue Retro local (`assets/dist/langs/fr/spells.json`) fait autorité pour les valeurs, les descriptions et les états. Le dump `assets/sources/starloco/sorts.sql` complète les filtres de cibles et les paramètres absents ; `game.sql` fournit les grades d'invocations. Les émulateurs ci-dessous sont des références techniques, et non une spécification Ankama.

| Mécanique | Règle retenue et source consultée |
| --- | --- |
| Branches aléatoires | Un tirage partagé sélectionne une ligne probabiliste ; les lignes garanties restent indépendantes. Roulette utilise le poids total des résultats du catalogue. [Spell.java, StarLoco](https://github.com/StarLoco/StarLoco-Game/blob/master/src/org/starloco/locos/fight/spells/Spell.java). |
| Brokle / Poisse | Brokle maximise les jets sur sa cible, Poisse minimise les jets du lanceur affecté ; Brokle prime en cas de rencontre. Descriptions locales 410/416 et [Formulas.java](https://github.com/StarLoco/StarLoco-Game/blob/master/src/org/starloco/locos/common/Formulas.java). |
| Armures Féca | Élément déterminé par le sort source ; les armures 265 utilisent les caractéristiques du lanceur, 105 celles du bénéficiaire. Les poisons contournent les armures élémentaires ordinaires. [Formulas.java](https://github.com/StarLoco/StarLoco-Game/blob/master/src/org/starloco/locos/common/Formulas.java). |
| Invocations | Modèle et grade exacts, sans repli sur un niveau d'exploration. Vie et caractéristiques principales évoluent avec le niveau de l'invocateur joueur ; PA/PM et résistances conservent les données du grade. [SummonFighter.java](https://github.com/StarLoco/StarLoco-Game/blob/master/src/org/starloco/locos/fight/SummonFighter.java). |
| Moquerie 203:6 | Le rang manque dans le lang local ; sa ligne est explicitement importée du dump. Aucun autre rang n'est utilisé comme remplacement. |
| Vitalesque | Plafond par tour, gains divisés par deux pour les coups provenant des joueurs/invocations. Les gains 108 sont de la vie temporaire : l'expiration retire la vie maximale et courante correspondante. [Fighter.java](https://github.com/StarLoco/StarLoco-Game/blob/master/src/org/starloco/locos/fight/Fighter.java). |
| Punition | Courbe maximale à 50 % de vie ; montant fondé sur la vie maximale de base et le pourcentage du rang. [SpellEffect.java](https://github.com/StarLoco/StarLoco-Game/blob/master/src/org/starloco/locos/fight/spells/SpellEffect.java). |
| Mot Lotof | **Début du prochain tour de la cible**, selon la description locale 427. Le déclencheur 1679 utilise la vie restante de cette cible. Divergence explicite : `refreshEndTurnBuff` de StarLoco déclenche en fin de tour ; cette différence n'est pas importée. [Ancienne description du sort](https://dofus.fandom.com/it/wiki/Mot_Lotof) recoupe le début de tour. |
| Laisse Spirituelle | Dernier personnage allié mort éligible, priorité sur les invocations ; lien de mort au lanceur. Description locale 420 et [SpellEffect.java](https://github.com/StarLoco/StarLoco-Game/blob/master/src/org/starloco/locos/fight/spells/SpellEffect.java). |
| Félintion | Vol de vie sur les ennemis, soin sur les alliés ; poussée dans les deux camps. La description locale 412 prime sur le filtre ancien du dump qui excluait les alliés de la poussée. |
| Peur / poussées collectives | Peur déplace le voisin dans la direction de la cellule cliquée sans dégâts de collision. Les poussées de zone traitent d'abord les cibles éloignées afin de libérer les cellules intermédiaires. Description locale 418 et [SpellEffect.java](https://github.com/StarLoco/StarLoco-Game/blob/master/src/org/starloco/locos/fight/spells/SpellEffect.java). |
| Ivresse | Le tonneau attire les ennemis en ligne lorsqu'il est au sol et soigne autour du porteur lorsqu'il est porté. Description locale 423, sorts 1674/1675 ; [description historique Pandawa](https://dofus-infos.webnode.page/les-classes-des-personnages/pandawa/). |
| Porter/jeter, rendu | Le client Retro ajoute `_C` avant la direction : `carring_CR`, `walk_CL`, `carringThrow_CR`, etc. `GAC.registerCarried(this)` désigne le point lu par `_mcCarried`. Les points des deux sprites Pandawa sont exportés, avec compensation du rééchantillonnage 20 → 60 images/s. Sources locales `dofus/aks/GameActions.as`, `ank/battlefield/SpriteHandler.as`, `ank/battlefield/mc/Sprite.as` et archive des sprites 120/121 ; voir [reconstruction des assets](asset-reconstruction.md). Observation navigateur encore requise. |
| Descendre d'un porteur | Le combattant porté peut marcher pendant son tour : le premier pas réussi rompt les deux liens, conserve le porteur sur sa cellule et consomme les PM normalement. Un chemin refusé ne détache personne. Référence technique consultée avant correction : `onFighterMovement` dans [Fight.java](https://github.com/StarLoco/StarLoco-Game/blob/master/src/org/starloco/locos/fight/Fight.java), recoupée par la [description historique](https://dofus-infos.webnode.page/les-classes-des-personnages/pandawa/). |
| Stabilisation et échange | La cible stabilisée ne peut pas être déplacée ; le lanceur stabilisé conserve ses propres sorts de déplacement. La restriction s'applique donc à la cible de Coopération/Transposition. [Description historique Pandawa](https://dofus-infos.webnode.page/les-classes-des-personnages/pandawa/). |
| Superposition de pièges | Deux pièges ne peuvent pas partager leur cellule centrale. Refus avant PA ; les zones périphériques peuvent se chevaucher. `canCast` de [Fight.java](https://github.com/StarLoco/StarLoco-Game/blob/master/src/org/starloco/locos/fight/Fight.java) et effet 400 de [SpellEffect.java](https://github.com/StarLoco/StarLoco-Game/blob/master/src/org/starloco/locos/fight/spells/SpellEffect.java). |
| Raulebaque | Positions enregistrées au départ, hors créatures apparues ensuite. Le moteur réserve les destinations avant de résoudre les cycles. Les personnages portés rejoignent leur propre position ; une invocation portée reste à l'ancienne position du porteur si elle est disponible, sinon la paire reste liée. Ce dernier arbitrage de collision est une décision explicite de cohérence du moteur : l'effet 784 de [SpellEffect.java](https://github.com/StarLoco/StarLoco-Game/blob/master/src/org/starloco/locos/fight/spells/SpellEffect.java) ne précise pas ce cas. |
| Zones | Alphabet `abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789-_` : `a=0`, `b=1`. Les croix X utilisent les voisins ±largeur/±(largeur−1). Sources locales `dofus/datacenter/Spell.as`, `ank/battlefield/ZoneHandler.as`, `ank/battlefield/mc/Zone.as` ; [PathFinding.java](https://github.com/StarLoco/StarLoco-Game/blob/master/src/org/starloco/locos/common/PathFinding.java). |

La matrice distingue disponibilité des données, exécution mécanique testée et observation visuelle. Un identifiant graphique 0/−1 signifie l'absence de fichier de sort dans le dump : pose, transformation, déplacement ou zone doivent alors être vérifiés séparément. Un fichier positif manquant constitue un défaut d'asset ; aucun résultat visuel n'est déduit de la seule présence d'un handler.
